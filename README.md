# GamerHub Ultra

GamerHub Ultra is een modern Nederlands gaming community platform gebouwd met React, TypeScript en Tailwind CSS.

## Functies

- **🔴 Live Gaming Nieuws Feed**: Automatische real-time RSS updates rechtstreeks van Gamer.nl, inclusief zoekfunctie, categoriefilters en cached fallback.
- **💬 Community Servers**: Maak en beheer Discord-achtige servers met eigen thematische kanalen (`#algemeen`, `#mc-builds`, toernooien) en live chat messaging.
- **👥 Vrienden & Direct Messages (DM's)**: Vrienden toevoegen via GamerTag, online status updates, actieve game activiteit, blokkeren/deblokkeren en 1-op-1 chatgesprekken.
- **🔗 Gekoppelde Accounts**: Koppel je PlayStation Network, Steam, Twitch, YouTube, Discord, Xbox en TikTok profielen met geverifieerde badges.
- **⚙️ Profiel & Statistieken**: Pas je avatar (met snelle DiceBear bots presets), status, totale uren, gamebibliotheek en trophy scores aan.
- **🛡️ Veilige In-App Modals**: Veilige modale vensters voor acties zoals het verwijderen van accounts en servers zonder storende browser pop-ups.

## Ontwikkeling & Build

```bash
# Start de lokale ontwikkelserver op poort 3000
npm run dev

# Productie build genereren
npm run build
```
